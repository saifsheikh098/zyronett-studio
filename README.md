# ZyroNett Studio — Website

A responsive, single-page agency website built with plain HTML, CSS and JavaScript. No framework, build process, or paid software required.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. For best results, test on Chrome desktop and mobile.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository, e.g. `zyronett-studio`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in Settings → Pages. It will typically look like `https://YOUR-USERNAME.github.io/zyronett-studio/`.

## Before publishing — important
- In `index.html`, replace `hello@zyronettstudio.com` with your real business email.
- Add your real Instagram and WhatsApp links (the current page does not invent or claim any).
- The three portfolio tiles are clearly marked concept visuals, not real client case studies. Replace them with your own reel links, designs, and work samples before presenting them as completed work.
- Check all contact links on your phone after publishing.
- The site loads Google Fonts from the internet; if unavailable, it falls back to system fonts.

## Files
- `index.html` — page content and layout
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and current year
